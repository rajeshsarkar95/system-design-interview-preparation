# Low-Level Design (LLD)

LLD focuses on classes, interfaces, object responsibilities and interactions.

For each problem:
1. Clarify use cases and constraints.
2. Identify entities and responsibilities.
3. Define interfaces and relationships.
4. Apply SOLID principles where useful.
5. Handle errors and concurrency.
6. Write a small implementation or class diagram.

Practice:
- Parking lot
- Elevator system
- Library management
- Vending machine
- Food ordering
- Notification service

Avoid overengineering. Use patterns only when they solve a real problem.
